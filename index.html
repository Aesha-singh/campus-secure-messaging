Features

CSCP + TLS 1.3+mTLS

Length-delimited binary frames (CRC32+MessagePack), single-threaded asyncio, ciphertext-only relay.

E2EE

X25519 key exchange, HKDF-SHA256, AES-256-GCM with per-message ratchet, TOFU pinning.

Store-and-Forward

Offline messages/files persisted (SQLite/WAL), replayed on reconnect with unread sync.

Files + Channels

Chunked transfer with sliding-window ACK, resume, quotas; server-mediated channels with live fan-out.

mDNS + Diagnostics

LAN discovery via _cscp._tcp.local., live RTT/jitter/loss in PyQt6 client.

Admin Dashboard

Stdlib HTTP/1.1 on :9444 serving /health, /metrics, live Canvas charts, optional Bearer token.
